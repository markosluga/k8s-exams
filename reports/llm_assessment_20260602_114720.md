## 1 — Domain Reassignment (121 questions)

All 236 questions were incorrectly tagged `Kubernetes Fundamentals`. Questions were re-analysed and reassigned to one of the four official KCNA exam domains based on their content.

### Reassignment logic

| Domain | Sub-topics used as criteria |
|---|---|
| **Kubernetes Fundamentals** | Core Concepts, Administration, Scheduling, Containerization |
| **Container Orchestration** | Networking (Services, Ingress, NetworkPolicy, DNS), Security (RBAC, Secrets, securityContext, admission), Storage (PV/PVC, StorageClass) |
| **Cloud Native Application Delivery** | Application Delivery (rollouts, Kustomize, deployment strategies), Debugging (kubectl logs/exec/describe/top/port-forward) |
| **Cloud Native Architecture** | Observability (Prometheus, tracing, Loki), Cloud Native Ecosystem (service mesh, CRDs, Operators, KEDA), Community (SIGs, TOC, KEPs, release cadence) |

- PromQL — `rate()`, instant query vs range query
- Alertmanager — inhibition, silences, grouping
- Distributed tracing — trace vs span parent-child relationship
- OpenTelemetry / OTLP — all three signals (traces, metrics, logs) over gRPC/HTTP
- Grafana Loki — label-only indexing vs Prometheus metric samples
- Three pillars of observability — metrics, logs, traces
- CNCF project maturity — Sandbox → Incubating criteria
- CRI (Container Runtime Interface) — gRPC interface, containerd / CRI-O
- Service mesh mTLS — data-plane proxy (Envoy) as enforcement point
- Kubernetes Operator pattern — CRD + controller reconciliation loop
- 12-factor app — factor III (config in env vars), factor XI (logs to stdout)
- CNCF cloud-native definition — official wording
- Immutable infrastructure principle — no in-place modification
- Sidecar vs Operator distinction — pod-scope vs cluster-scope
- KEDA — event-driven autoscaling, scale-to-zero capability
- Kubernetes SIGs — self-governing contributor groups by area
- CNCF TOC — project acceptance and graduation authority
- Kubernetes release cadence — ~4 months / 3 releases per year
- KEP (Kubernetes Enhancement Proposal) — design doc for significant changes
- Beta API deprecation guarantee — 9 months or 3 minor releases, whichever is longer
